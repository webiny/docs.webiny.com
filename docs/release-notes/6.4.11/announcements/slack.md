Webiny 6.4.11 is out! :rocket:

This one focuses on squashing a few bugs that snuck in. Most importantly, we fixed a crash that was breaking page loading in React Server Components — if you were seeing that `viewportManager.setBreakpoints` error, you can breathe easy now.

We also fixed page search in the Website Builder for those using DynamoDB + OpenSearch, which was returning empty results no matter what you typed. That's working as expected again. Check out the changelog to learn more.
