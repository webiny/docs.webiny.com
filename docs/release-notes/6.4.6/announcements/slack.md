Webiny 6.4.6 is out! :rocket:

This release is all about polish and usability fixes. The page editor's settings sidebar now scrolls properly so you can actually reach all those form fields, and background images display their thumbnails correctly instead of a generic file icon. Long file names no longer break the layout either — everything stays tidy with proper truncation.

We've also improved the DataTable columns menu so you can toggle multiple columns without it closing on you, and fixed an issue where pages created via integrations couldn't be translated. Small but meaningful improvements across the board. Check out the changelog to learn more.
