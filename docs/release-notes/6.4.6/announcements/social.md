Webiny 6.4.6 is now live 🚀

Highlights:
→ DataTable columns menu — stays open for multi-select and keeps the settings cog pinned to the right edge
→ Page editor sidebar scroll — all form fields are now accessible, no more cut-off content
→ Background image thumbnails — the Style panel now shows actual image previews instead of generic file icons
→ Long file name handling — truncated with ellipsis so action buttons stay visible
→ Page translation fix — pages created via integrations can now be translated without errors
