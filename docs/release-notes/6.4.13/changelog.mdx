## Breaking Changes

### Stricter Identity Token Verification ([#6282](https://github.com/webiny/webiny-js/pull/6282))
> ⏳ REVIEW-PENDING `@brunozoric`: confirm this entry, then delete this line.

Cognito access tokens are no longer accepted by the API. You must send the ID token instead. This change applies to all API requests that require authentication.

### Stricter Field Validation in Generic CMS Queries ([#6282](https://github.com/webiny/webiny-js/pull/6282))
> ⏳ REVIEW-PENDING `@brunozoric`: confirm this entry, then delete this line.

The `fields` argument in generic `cms` queries and mutations now accepts only field names separated by dots (e.g., `values.author.name`). Any other value returns an error. If you were passing malformed or unexpected values to the `fields` argument, update your queries to use valid dot-separated field paths.
