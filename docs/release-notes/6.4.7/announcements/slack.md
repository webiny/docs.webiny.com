Webiny 6.4.7 is out! :rocket:

A quick maintenance release to smooth out a few rough edges! We've fixed some quirks in the Headless CMS — the scheduler now handles missing AWS events gracefully, and drag-and-drop folder moves properly wait for your confirmation before updating the UI.

We also tidied up the Dynamic Zone template editing experience and fixed a layout issue where long content model names were causing sidebar overflow chaos. Small fixes, but they add up to a nicer day-to-day experience. Check out the changelog to learn more.
