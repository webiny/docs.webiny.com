Webiny 6.5.2 is here 🚀

Highlights:

→ Vue and Nuxt SDKs — now at parity with the Next.js SDK, complete with live preview support
→ MFA reset for admins — reset a user's multi-factor authentication directly from the Admin panel
→ TOTP QR codes generated locally — your authenticator secret never leaves the browser
→ Fixed scheduled publish/unpublish on AWS — entries and pages now execute on time as expected
→ Custom CMS field renderers — publicly exposed API for building your own field renderers
→ Stricter permission and access checks — tightened security across entries, folders, webhooks, and more

As always, full details in the release notes 👇
