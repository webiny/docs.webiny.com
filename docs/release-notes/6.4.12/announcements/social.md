Webiny 6.4.12 is here 🚀

Highlights:
→ Per-webhook signing secrets — configure individual secrets for each webhook instead of relying on a global one
→ Debug logger tool — troubleshoot issues in deployed environments with an opt-in debugger that returns debug payloads in GraphQL responses
→ Stricter permission checks — entry access, folder publishing, API keys, and roles now validate against caller permissions
→ Full-text search fixes — OpenSearch queries no longer fail on mixed-type fields like dates, numbers, or booleans
→ Workflow controls in page editor — workflow state now properly reflected in the editor with correct publish controls
→ Page revision management fixes — revisions cache updates immediately, delete mutation now works, and confirmation dialogs added

As always, full details in the release notes 👇
