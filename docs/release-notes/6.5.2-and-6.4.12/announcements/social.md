Webiny 6.5.2 and 6.4.12 are here 🚀

6.5.2 highlights:

→ Vue and Nuxt SDKs: now at parity with the Next.js SDK, including live preview
→ MFA reset for admins: reset a user's multi-factor authentication directly from the Admin
→ TOTP QR codes generated locally: your authenticator secret never leaves the browser
→ Scheduled publish/unpublish on AWS: entries and pages publish on time again
→ Custom CMS field renderers: a public API for building your own field renderers

6.4.12 highlights:

→ Per-webhook signing secrets: configure a secret for each webhook instead of one global secret
→ Debug logger tool: an opt-in debugger that returns debug payloads in GraphQL responses
→ Website Builder fixes: page revisions update immediately, revision delete works, and workflow controls show correctly in the page editor
→ Full-text search fixes: OpenSearch queries no longer fail on date, number or boolean fields

Both releases: stricter permission checks across entries, folders, API keys, roles, webhooks and more.

As always, full details in the release notes 👇
