Webiny 6.5.0 is out! :rocket:

This is a big one! AI content generation is now built right into the CMS — describe what you want and watch your entry fields populate in real time. We've also added field-level comments and a notifications inbox, so your team can collaborate directly on content without leaving the editor.

On the media side, there's a new Asset field with non-destructive cropping and focal point selection. Pick your crop, set a focal point, and the delivery URL handles everything — your original file stays untouched. We've also made scheduling timezone-aware, so you can pick a publish time in any timezone and know exactly when content goes live.

There's plenty more in this release — a command palette (⌘K), Google and OpenRouter AI providers, better reference field search, and a redesigned model editor among them. Check out the changelog to learn more.
