## Headless CMS

### Fixed "New Revision" Button Not Working on Reviewed, Published Entries ([#6325](https://github.com/webiny/webiny-js/pull/6325))
> ⏳ REVIEW-PENDING `@adrians5j`: confirm this entry, then delete this line.

When using content review workflows, clicking "New Revision" on an approved and published entry did nothing — no request was sent and no revision was created. The only workaround was the "Create New Revision" option in the menu, which discarded any unsaved edits.

This has been fixed. The "New Revision" button now works correctly on published entries: it creates a new draft revision that preserves your edits and goes through the review workflow again before it can be published. The button is also disabled while a revision is being created to prevent duplicate revisions from repeated clicks.
