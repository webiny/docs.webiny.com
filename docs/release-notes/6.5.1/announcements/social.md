Webiny 6.5.1 is now available 🚀

Highlights:
→ Multi-tenant user improvements — one Cognito account can now be shared across tenants with automatic routing and a tenant switcher
→ New step-by-step birthday picker — guides users through month, day, and year selection for a smoother date-of-birth experience
→ Bulk actions no longer abort on failure — errors are recorded per item while processing continues for remaining selections
→ Translate action restored for all users — manual translation workflow now works again without requiring AI Powerups license
→ Fixed rich text fields not saving when cleared — Lexical editor now correctly detects empty state after content deletion
→ Tenant renames now sync properly — name and description changes in Tenant Manager propagate across the platform

As always, full details in the release notes 👇
